# Personal portfolio — Next.js

An editorial, motion-first portfolio starter for an AI developer, creator, and explorer.

## Run locally

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Main files

- `app/page.tsx` — portfolio content, project data, and section structure.
- `app/globals.css` — visual system, responsive layout, typography, and art direction.
- `components/scroll-effects.tsx` — Lenis smooth scrolling, GSAP reveals, parallax, cursor, and magnetic interactions.

## Personalize first

1. Replace `your name`, `hello@yourname.dev`, and the social links in `app/page.tsx`.
2. Swap the Unsplash placeholder images for your own work, portrait, and video thumbnails.
3. Update the `projects` array with real problem statements, solutions, GitHub URLs, and demo links.

## Checks

```bash
npm run typecheck
npm run build
```
